# اخبار سایت (content/news)

هر خبر یک فایل JSON است: `content/news/<slug>.json`، و کاور آن در `content/news/covers/`.
اسکریپت `scripts/import-news.ts` این فایل‌ها را وارد جدول News می‌کند.

## قالب فایل

```json
{
  "slug": "sahm-savabegh-tahsili-konkur-1406",
  "title": "عنوان خبر",
  "summary": "خلاصهٔ کوتاه برای کارت خبر و گوگل (حداکثر ۱۶۰ نویسه)",
  "category": "EXAM",
  "pinned": false,
  "publishedAt": "2026-10-25T12:00:00+03:30",
  "cover": "covers/sahm-savabegh-tahsili-konkur-1406.webp",
  "tags": ["کنکور ۱۴۰۶"],
  "formSlug": null,
  "productSlug": null,
  "body": [
    "پاراگراف اول با **متن پررنگ** و [لینک داخلی](/konkur-nasimshahr).",
    "",
    "## زیرعنوان",
    "- مورد فهرست",
    "",
    "منبع: [نام منبع](https://example.ir/...)"
  ]
}
```

| فیلد | الزامی | توضیح |
|---|---|---|
| `slug` | بله | فقط حروف کوچک لاتین، عدد و خط تیره (`^[a-z0-9]+(-[a-z0-9]+)*$`). نام فایل باید دقیقاً `<slug>.json` باشد. آدرس خبر: `/news/<slug>` |
| `title` | بله | عنوان فارسی |
| `summary` | نه | حداکثر ۱۶۰ نویسه (بیش از ۳۰۰ رد می‌شود) |
| `category` | نه | یکی از `ANNOUNCE` `EXAM` `CLASSES` `RESULTS` `BOOKLET` `GENERAL` (پیش‌فرض `GENERAL`) |
| `pinned` | نه | `true` = سنجاق بالای فهرست اخبار |
| `published` | نه | پیش‌فرض `true`؛ `false` = پیش‌نویس (فقط در پنل مدیریت دیده می‌شود) |
| `publishedAt` | نه | تاریخ ISO با منطقهٔ زمانی (`+03:30`). تاریخ آینده = انتشار زمان‌بندی‌شده؛ خبر از همان لحظه خودکار نمایش داده می‌شود |
| `cover` | نه | مسیر نسبی داخل همین پوشه، `webp`/`jpg`/`png`، حداکثر ۵ مگابایت، پیشنهاد ۱۲۰۰×۶۷۵ |
| `body` | بله | آرایه‌ای از خطوط (یا یک رشته). زیرمجموعهٔ امن markdown: `##` `###` `-` `1.` `>` `**پررنگ**` `[متن](https://…)` یا `[متن](/مسیر)`. HTML به‌صورت متن ساده نمایش داده می‌شود |
| `formSlug` / `productSlug` | نه | دکمهٔ اقدام زیر خبر: نامک یک فرم ثبت‌نام یا یک جزوه |
| `tags`، `coverAlt` | نه | برای نویسنده نگه داشته می‌شوند؛ فعلاً در سایت ذخیره نمی‌شوند |

## قواعد ورود (ایمن برای اجرای خودکار)

- فقط **ساختن**: اگر خبری با همین `slug` وجود داشته باشد، دست نمی‌خورد (ویرایش‌های مدیر حفظ می‌شود).
- هیچ خبری حذف نمی‌شود. خبری که مدیر حذف کرده، دوباره ساخته نمی‌شود (فهرست اسلاگ‌های واردشده در تنظیم `newsFeed` نگه داشته می‌شود).
- برای اصلاح خبری که قبلاً منتشر شده، از پنل مدیریت (`/admin/news`) استفاده کنید؛ تغییر JSON آن اثری ندارد.
- کاور در `UPLOAD_DIR/public/news/feed/` کپی و از `/media/news/feed/<file>` سرو می‌شود؛ فایل هم‌نام موجود بازنویسی نمی‌شود، پس برای کاور جدید نام تازه بگذارید.
- فایل خراب گزارش و رد می‌شود و بقیه وارد می‌شوند.

## انتشار یک خبر تازه

1. فایل `content/news/<slug>.json` و کاور آن را در `content/news/covers/` روی شاخهٔ **`news-feed`** بگذارید و push کنید.
2. سرور (تایمر `setareganplus-news.timer`) شاخه را در `/var/lib/setareganplus-news` دریافت و خبر را وارد می‌کند. گزارش: `/var/log/setareganplus-news.log`.
3. برای انتشار فوری روی سرور: `systemctl start setareganplus-news.service`

اجرای دستی:

```bash
npx tsx scripts/import-news.ts --dir content/news --dry-run   # فقط نمایش
npx tsx scripts/import-news.ts --dir content/news
```

## قواعد محتوا

- فقط اطلاعات واقعی و قابل‌استناد، با «منبع: …» و لینک در پایان متن؛ بدون کپی عین متن.
- بدون وعدهٔ قبولی، رضایت‌نامهٔ ساختگی، نام یا رتبهٔ افراد بدون اجازه، و بدون موضوع سیاسی، پزشکی یا مالی.
- برنامه، قیمت یا تاریخی که رسمی نیست ننویسید؛ به‌جای آن: «برای اطلاع از زمان دقیق با آموزشگاه تماس بگیرید».
